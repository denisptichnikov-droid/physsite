# coil-magnet-3d — Магнит и катушка: откуда берётся ток

**Коды:** 3.4.1, 3.4.2, 3.4.3, 3.4.5. **Файл:** `models/coil-magnet-3d.js` (three.js через `models/_3d.js`).

## Что показывает
Полосовой магнит (N красный, S синий) движется вдоль оси неподвижной катушки вперёд-назад, в крайних точках стоит 0,7 с. Яркие линии B проходят сквозь виток, бледные нет; число ярких линий пропорционально потоку. На витках движутся электроны (против стрелки тока I), вокруг катушки показано вихревое поле E, внизу гальванометр. В катушке показаны вектор B магнита и вектор B индукционного тока. Подпись под рисунком: «Поток растёт → B_инд против B магнита», «Поток падает → B_инд по B магнита», «Магнит стоит → поток не меняется → тока нет». Под ней графики Φ(t) и I(t) за последние 8 с. Кнопка «Вид как в задании» даёт плоский вид сбоку: сечения витков ⊙ и ⊗, линии только в плоскости рисунка.

## Параметры (key)
- `pos` — положение магнита d, 0–5 усл. ед. (шаг 0,1; 0 — центр магнита в центре катушки). Движение слайдера останавливает анимацию; магнит догоняет слайдер со скоростью 2 ед./с, и пока он едет, виден ток.
- `turns` — число витков N, 1–8.
- `pole` — полюс, обращённый к катушке: `N`, `S`.
- `speed` — скорость магнита в анимации, 0–2 ед./с (0 — магнит стоит, тока нет).
- Кнопки: Пауза/Пуск (пауза останавливает магнит, поэтому ток равен нулю), Сброс, Вид как в задании.

## Формулы
Из B3: $\Phi=BS\cos\alpha$ (3.4.1), $\mathcal E_i=-\Delta\Phi/\Delta t$ и катушка из N витков (3.4.3), правило Ленца (3.4.5).

Величины условные. Магнит заменён двумя полюсами на $\pm A$ от центра ($A=0{,}9$), радиус витка $R=1{,}25$. Поток через один виток:
$$\Phi(d)=\frac{c(d+A)-c(d-A)}{2c(A)},\qquad c(u)=\frac{u}{\sqrt{u^2+R^2}},\qquad \Phi(0)=1.$$
$$\left|\frac{\Delta\Phi}{\Delta t}\right|=\left|\frac{d\Phi}{dd}\right|\,|v|,\qquad |\mathcal E|\sim N\left|\frac{\Delta\Phi}{\Delta t}\right|,\qquad I\sim\mathcal E\ \text{(сопротивление принято равным 1)}.$$
Линии поля — изолинии той же функции: линия проходит сквозь виток, только если её уровень меньше $\Phi(d)$. Уровней 8, сечений 4, всего 32 линии. Поток считается через один виток: витки считаются одинаковыми.

Направление: поле индукционного тока направлено против изменения потока. Со стороны магнита: N приближается — против часовой, N удаляется — по часовой; S приближается — по часовой, S удаляется — против часовой.
