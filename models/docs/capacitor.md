# capacitor — Плоский конденсатор

**Что показывает:** пластины (+q слева, −q справа), однородное поле между ними (густота линий ∝ E), диэлектрик при ε > 1, источник с ключом. Режим «подключён» — U = const; «отключён» — q фиксируется в момент отключения, U пересчитывается. Стрелки ↑/↓ — изменение относительно последнего переключения режима (или сброса).

**Параметры:** d = 1–10 мм (шаг 0,5), S = 50–500 см² (шаг 10), ε = 1–10 (шаг 0,5), U_ист = 10–300 В (шаг 10; в режиме q = const неактивен).

**Формулы (B, 3.1.9, 3.1.11, 3.1.4):** $C=\varepsilon\varepsilon_0S/d$, $q=CU$, $E=U/d$, $W=CU^2/2=q^2/(2C)$; $\varepsilon_0=8{,}85\cdot10^{-12}$ Ф/м.

**Контрольные наборы:**
1. d = 2 мм, S = 200 см², ε = 1, U = 100 В, подключён: C = 8,85·10⁻¹¹ Ф, q = 8,85·10⁻⁹ Кл, E = 5·10⁴ В/м, W ≈ 4,42·10⁻⁷ Дж.
2. Из набора 1 отключить, затем d = 4 мм: C = 4,43·10⁻¹¹ Ф ↓, q = 8,85·10⁻⁹ Кл (не изм.), U = 200 В ↑, E = 5·10⁴ В/м (не изм.), W = 8,85·10⁻⁷ Дж ↑.
3. Из набора 1 отключить, затем ε = 2: C = 1,77·10⁻¹⁰ Ф, U = 50 В, E = 2,5·10⁴ В/м, W ≈ 2,21·10⁻⁷ Дж.
4. Подключён, d = 2 мм, S = 200 см², ε = 4, U = 100 В: C = 3,54·10⁻¹⁰ Ф, q = 3,54·10⁻⁸ Кл, E = 5·10⁴ В/м, W = 1,77·10⁻⁶ Дж.
