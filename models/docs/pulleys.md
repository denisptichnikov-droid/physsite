## pulleys — Система тел: нити и блоки (1.2.4, 1.2.5, 1.2.8)

**Что показывает.** Три схемы (переключатель): (1) машина Атвуда; (2) брусок m₁ на столе (μ) + висящий m₂ через блок на краю стола; (3) m₁ на подвижном блоке, m₂ на свободном конце нити (второй конец нити закреплён на потолке, нить через неподвижный блок); нумерация как на странице newton-laws и в B6: a₂ = 2a₁. Силы →T, m→g, →N, →F_тр, ускорения →a₁, →a₂, анимация («Пуск»). В схеме 3 подпись a₂ = 2a₁ (нерастяжимость нити: Δl₂ = 2Δl₁). Нити и блоки невесомые, нить нерастяжима.

**Параметры.** m₁, m₂ 0,1…5 кг; μ 0…1 (только схема 2).

**Формулы (1.2.4, 1.2.8, B6).**
(1) a = |m₁ − m₂|g/(m₁ + m₂), T = 2m₁m₂g/(m₁ + m₂).
(2) покой, если m₂g ≤ μm₁g: a = 0, T = F_тр.покоя = m₂g; иначе a = (m₂ − μm₁)g/(m₁ + m₂), T = m₂(g − a), F_тр = μm₁g; N = m₁g.
(3) m₂g − T = m₂a₂, 2T − m₁g = m₁a₁, a₂ = 2a₁ ⇒ a₁ = (2m₂ − m₁)g/(4m₂ + m₁), T = m₂(g − a₂) (a₂ — проекция на ось вниз); равновесие при m₁ = 2m₂.
