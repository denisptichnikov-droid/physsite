# em-spectrum — Шкала электромагнитных волн

**Коды:** 3.5.5, 3.5.6, 4.1.2. **Файл:** `models/em-spectrum.js`.

## Что показывает
Логарифмическая шкала λ от 10⁻¹³ до 10⁴ м (слева длинные волны, справа короткие) с диапазонами радио, СВЧ, ИК, видимый, УФ, рентген, γ; схема волны; увеличенная полоса видимого спектра 380–760 нм с маркером. Readout: λ, ν, E (Дж и эВ), диапазон, цвет (для видимого), источники, применение.

## Параметры
- Слайдер хранит u = −lg λ, u ∈ [−4; 13], шаг 0,01 (вправо — короче λ). По умолчанию u = 6,26 (λ ≈ 5,5·10⁻⁷ м).

## Границы диапазонов
<!-- CHECK: границы условные, диапазоны в природе перекрываются (рентген/γ — по источнику, а не по λ) -->
γ < 10⁻¹¹ м ≤ рентген < 10⁻⁸ м ≤ УФ < 380 нм ≤ видимый < 760 нм ≤ ИК < 1 мм ≤ СВЧ < 1 м ≤ радио. Цвета: фиолетовый 380, синий 440, голубой 485, зелёный 500, жёлтый 565, оранжевый 590, красный 625–760 нм (приблизительно). Цвета полосы — физические (не из темы).

## Формулы
- $\nu = c/\lambda$ (4.1.2, 3.6.10), c = 3·10⁸ м/с
- $E = h\nu = hc/\lambda$ (4.1.1–4.1.2), h = 6,6·10⁻³⁴ Дж·с; $E_{эВ} = E/1{,}6\cdot10^{-19}$
