## energy-bars — Превращения механической энергии
Коды: 1.2.7, 1.2.8, 1.4.6, 1.4.7, 1.4.8.

**Что показывает.** Три сценария: (1) тело в желобе (склон — горизонтальный участок 2 м — склон, края 2,5 м), старт без скорости с высоты h, трение μ (по желанию) только на горизонтальном участке; (2) груз на горизонтальной пружине; (3) груз на вертикальной пружине. Столбики E_к, E_п (E_упр, E_тяж), Q и суммарный столбик меняются синхронно с движением. Без трения сумма постоянна (E₁ = E₂), с трением E₁ = E₂ + Q; тело останавливается на шероховатом участке, Q → mgh.

**Параметры.** m 0,5–5 кг; h 0,2–2,4 м; μ 0–0,5; k 20–400 Н/м; A 0,05–0,3 м.

**Формулы.** E_к = mv²/2 (1.4.6); E_п = mgh, E_п = kx²/2 (1.4.7); E₁ = E₂ и E₁ = E₂ + Q (1.4.8); Q = μmg·s (1.2.8, 1.4.4); kΔl₀ = mg (1.2.7); ω = √(k/m), v_max = ωA (1.5.1–1.5.2). Путь по шероховатому участку до остановки s = h/μ (из mgh = μmg·s). Вертикальная пружина: E = mv²/2 + kΔl²/2 + mgh, Δl = Δl₀ + x (x вниз от равновесия), h отсчитывается от нижней точки.

**Контрольные наборы.**
1. Горка, m = 1 кг, h = 2 м, μ = 0: E₁ = 20 Дж; внизу E_к = 20 Дж, v = √40 ≈ 6,32 м/с.
2. Горка, m = 2 кг, h = 1 м, μ = 0,2: E₁ = 20 Дж; за один проход горизонтального участка Q = 0,2·2·10·2 = 8 Дж; s = h/μ = 5 м; в конце Q = 20 Дж.
3. Горизонтальная пружина, m = 1 кг, k = 100 Н/м, A = 0,1 м: ω = 10 рад/с, E = 0,5 Дж, v_max = 1 м/с.
4. Вертикальная пружина, m = 1 кг, k = 100 Н/м, A = 0,1 м: Δl₀ = 0,1 м; внизу E_упр = 2, E_тяж = 0, E_к = 0; в равновесии E_упр = 0,5, E_тяж = 1, E_к = 0,5; вверху E_упр = 0, E_тяж = 2, E_к = 0; E_полн = 2 Дж.

**Ограничения.** Движение по желобу считается численно (тело — точка, склоны гладкие), скорость на каждом шаге согласуется с законом энергии. Статическое удлинение вертикальной пружины на рисунке не в масштабе.
