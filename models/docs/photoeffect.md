# Фотоэффект (`photoeffect`)
Коды: 4.1.1, 4.1.2, 4.1.3, 4.1.4.

## Что показывает
Фотоэлемент: свет падает на катод, из него вылетают электроны (их число зависит от интенсивности, скорость — от √E_кин). Между анодом и катодом приложено напряжение U. Под фотоэлементом — ВАХ I(U) с отметками −U_зап и I_нас и текущей точкой.

## Параметры
- Металл катода (A_вых): цезий 1,9; калий 2,2; натрий 2,3; цинк 4,2; платина 5,3 эВ. **CHECK:** табличные значения приблизительные, эксперту сверить с задачниками/ФИПИ.
- λ: 100–800 нм, шаг 5 (подпись УФ / видимый / ИК).
- Интенсивность: 0–100 %, условно n = (интенсивность, %)·10¹² фотоэлектронов в 1 с.
- U = φ_анода − φ_катода: от −12 до +12 В, шаг 0,1.

## Формулы (часть B)
- ν = c/λ; E = hν = hc/λ (4.1.1, 4.1.2)
- hν = A_вых + E_кин max; A_вых = hν_кр = hc/λ_кр; E_кин max = mv²_max/2 = eU_зап (4.1.4)
- I_нас = e·n (n ∝ интенсивности, Умскул к 4.1.4)
- ВАХ: I = 0 при U ≤ −U_зап; I = I_нас при U ≥ 1 В; между ними I = I_нас·(1 − (1 − x)²), x = (U + U_зап)/(U_зап + 1). Форма этого участка **качественная**, точные только U_зап и I_нас.
Константы: h = 6,6·10⁻³⁴, c = 3·10⁸, e = 1,6·10⁻¹⁹, m_e = 9,1·10⁻³¹, 1 эВ = 1,6·10⁻¹⁹ Дж.
