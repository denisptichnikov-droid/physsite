# lens-builder — Построение изображения в тонкой линзе

Коды: 3.6.6, 3.6.7, 3.6.8.

**Что показывает.** Главная оптическая ось, линза (собирающая — стрелки на концах, рассеивающая — «вилки»), фокусы F и 2F с обеих сторон. Предмет AB (стрелка, перетаскивается: за вершину — d и H, за ствол — d). Три стандартных луча: через оптический центр (без преломления); параллельно оси → через фокус (у рассеивающей — продолжение через мнимый фокус штрихом); через фокус (или направленный в фокус) → параллельно оси. Мнимые продолжения и мнимое изображение — штрихом. Третий луч не рисуется, если пересекает плоскость линзы за пределами рисунка.

**Изображение за рисунком.** Если изображение не помещается, на рисунке появляется плашка с |f| и h и стрелка в сторону изображения. Когда предмет близко к фокусу (|d − F|/F < 0,35), плашка объясняет: лучи после линзы почти параллельны.

**Луч под углом (флажок).** Луч падает на линзу на высоте 6 см под углом φ к главной оси (φ > 0 — идёт вниз). Побочная ось проходит через O параллельно лучу и пересекает фокальную плоскость в точке P на расстоянии |F|·tg φ от главной оси. Преломлённый луч идёт через P; у рассеивающей линзы P лежит на передней фокальной плоскости, и через неё проходит продолжение луча (штрих). Обычные лучи при этом приглушены. Формула |F|·tg φ — геометрия построения, в базе формул её нет.

**Параметры.** Тип линзы; |F| = 2…15 см (шаг 0,5); d = 1…40 см (шаг 0,5); H = 0,5…6 см; флажок `cbOblique`; φ = `sAng` = −30…30° (шаг 1). Показания — в метрах; d и F — в блоке «Ещё величины».

**Формулы (B4, 3.6.7).** 1/d + 1/f = 1/F ⇒ f = Fd/(d − F); F < 0 у рассеивающей; f < 0 — мнимое; D = 1/F; Γ = |f|/d; h = ΓH.

**Предельные случаи.** Собирающая, d = F: изображения нет, «лучи параллельны, изображение на бесконечности», f = ∞, Γ = —. Рассеивающая: d − F = d + |F| > 0 всегда, деления на 0 нет. d = 2F → Γ = 1 («равное»).
