# carnot — Цикл Карно

**Что показывает.** Цикл Карно на pV-диаграмме: две изотермы (T_н — красная, T_х — синяя) и две адиабаты (Q = 0). Стрелки показывают направление обхода, подписи Q_н и Q_х — полученную и отданную теплоту. Рядом столбики Q_н, A и |Q_х|: столбик |Q_х| стоит на вершине A, поэтому видно Q_н = A + |Q_х|. Шкала столбиков постоянная, 2000 Дж на всю высоту.

**Параметры.** T_н = 200…1000 К, T_х = 0…T_н (шаг 10 К). На слайдерах значения показаны и в °C (t = T − 273). Q_н = 100…2000 Дж, шаг 50 (`sQ`), по умолчанию 1000. Масштаб диаграммы условный: νR = 1, V₁ = 1,5, V₂ = 2V₁.

**Формулы (часть B).** 2.2.10: η_max = 1 − T_х/T_н (T в кельвинах). 2.2.9: η = A/Q_н = 1 − |Q_х|/Q_н, отсюда A = ηQ_н, |Q_х| = Q_н − A. 2.1.7: T = t + 273. 2.2.7: на адиабате Q = 0.

**Предельные случаи.**
- T_х = T_н: η = 0, адиабаты вырождаются, площадь цикла равна 0.
- T_х = 0: η = 100 %, адиабаты уходят в бесконечность, рисунок обрезан. Модель отмечает, что этот случай недостижим.
- Деления на 0 нет: T_н ≥ 200 К; при T_х = 0 объёмы равны Infinity и обрезаются.

**Контрольные наборы.**
| T_н | T_х | η_max |
|---|---|---|
| 500 К | 300 К | 40,0 % |
| 380 К (107 °C) | 280 К (7 °C) | 26,3 % |
| 400 К | 400 К | 0 % |
| 1000 К | 0 К | 100 % |
| 1000 К | 250 К | 75,0 % |

С теплотой: T_н = 500 К, T_х = 300 К, Q_н = 1000 Дж — A = 400 Дж, |Q_х| = 600 Дж. T_н = 1000 К, T_х = 250 К, Q_н = 2000 Дж — A = 1500 Дж, |Q_х| = 500 Дж. T_х = T_н — A = 0, |Q_х| = Q_н. T_х = 0 — A = Q_н, |Q_х| = 0 (показания отмечают, что это недостижимо).
