# refraction — Преломление света и ПВО

Коды: 3.6.2, 3.6.4, 3.6.5.

**Что показывает.** Луч падает из среды 1 (сверху) на границу со средой 2 (снизу). Нормаль — штрих, углы α (падения), γ = α (отражения), β (преломления) — дуги от нормали. При n₁ > n₂ штрихом отмечен предельный угол α_пр; при α ≥ α_пр преломлённого луча нет, надпись «полное внутреннее отражение». Яркость отражённого луча — качественно (формулы Френеля, вне части B, на числа не влияет).

**Параметры.** n₁, n₂ ∈ {воздух 1,0; вода 1,33; стекло 1,5; алмаз 2,42}; α = 0…90° (шаг 1°), слайдер или перетаскивание источника S.

**Формулы (B4).** 3.6.4: n₁ sin α = n₂ sin β; n = c/v; n_отн = n₂/n₁. 3.6.5: sin α_пр = n₂/n₁ (n₁ > n₂). 3.6.2: γ = α. c = 3·10⁸ м/с.

**Предельные случаи.** α = 0 → β = 0. α = 90° при n₁ < n₂ → β = arcsin(n₁/n₂). n₁ = n₂ → β = α. sin β ≥ 1 → ПВО (β не считается, NaN не возникает).
