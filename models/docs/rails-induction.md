# rails-induction — Проводник на рельсах в магнитном поле

**Коды:** 3.4.1, 3.4.3, 3.4.4, 3.4.5, 3.3.3. **Файл:** `models/rails-induction.js`.

## Что показывает
Два горизонтальных рельса, замкнутых слева резистором R; перемычка длиной l движется со скоростью v (знак: + вправо). Поле B ⊥ плоскости (⊙/⊗). Закрашена площадь контура S = l·x, показаны: стрелки индукционного тока по контуру, →v, →F_A (всегда против →v). Сопротивлением перемычки и рельсов пренебрегаем. Анимация замедлена в 10 раз; дойдя до края (x = 2 м или 0,15 м), перемычка останавливается (анимация на паузе, readout показывает значения у края); следующий «Пуск» начинает новый проход с начала рельсов.

## Параметры
- B: 0,1…2 Тл (0,5); l: 0,2…1 м (0,4); v: −5…5 м/с, шаг 0,5 (2); R: 0,5…10 Ом (2); B ⊙/⊗ (⊗). x стартует с 0,5 м.
- v = 0 → ℰ = I = F = 0, стрелок нет.

## Формулы
- $\Phi = BS$, $S = lx$ (3.4.1); $|\Delta\Phi/\Delta t| = Blv$ (3.4.3)
- $\mathcal E = Blv$ (3.4.4, l ⊥ B, v ⊥ B); $I = \mathcal E/R$ (3.2.3)
- $F_A = IBl$ (3.3.3, α = 90°)
- Направление (3.4.5, Ленц): B ⊙ и v вправо (поток растёт) → ток по часовой; смена знака B или v меняет направление. Проверка силой Лоренца: q·v×B для v = +x, B = +z даёт −y — ток в перемычке вниз, т.е. по часовой ✓. Сила Ампера I·l×B — против v.
