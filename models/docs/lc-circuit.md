# lc-circuit — Идеальный колебательный контур

**Коды:** 3.5.1, 3.5.2, 3.1.11, 3.4.7. **Файл:** `models/lc-circuit.js`.

## Что показывает
Схема (конденсатор со знаками зарядов и полем E между обкладками, катушка, стрелки тока), столбики W_C, W_L, W (сумма = const), синхронные графики q(t) и I(t) на два периода с бегущей отметкой. Анимация замедлена (один период — 4 с). q — заряд верхней обкладки; I > 0 — ток к верхней обкладке.

## Параметры
- L: 1…200 мГн (10); C: 1…100 мкФ (10); q_max: 10…500 мкКл, шаг 10 (100). Все > 0 → деления на 0 нет.

## Формулы
- $q = q_{max}\cos\omega t$, $I = -\omega q_{max}\sin\omega t$ — это форма B3.5.1 $q = q_{max}\sin(\omega t+\varphi_0)$ с $\varphi_0 = \pi/2$ (в t = 0 конденсатор заряжен полностью).
- $T = 2\pi\sqrt{LC}$, $\omega = 1/\sqrt{LC}$, $\nu = 1/T$, $I_{max} = \omega q_{max}$, $U_{max} = q_{max}/C$ (3.5.1, 3.1.9)
- $W_C = q^2/(2C)$ (3.1.11), $W_L = LI^2/2$ (3.4.7), $W = q_{max}^2/(2C)$ (3.5.2); $\lambda = cT$, c = 3·10⁸ м/с.
