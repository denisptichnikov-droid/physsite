## lever-moments — Рычаг: правило моментов (1.3.1, 1.3.2, 1.3.3)

**Что показывает.** Балка 2 м с делениями на опоре O (положение настраивается), 2–3 груза на балке, силы →Fᵢ = mᵢg (вниз от балки), размерные линии плеч lᵢ. Если M_по ≠ M_против — штриховая наклонённая балка и круговая стрелка «повернётся по/против часовой». Флажок «масса балки» — сила M→g в середине балки.

**Параметры.** x_O 0…2 м; m₁, m₂, m₃ 0…5 кг; x₁, x₂, x₃ 0…2 м (шаг 0,1); третий груз — флажок; масса балки M 0…5 кг — флажок.

**Формулы.** 1.3.1 |M| = Fl, l = |xᵢ − x_O|; 1.3.3 равновесие M_по = M_против (ΣM = 0), N = Σmᵢg; 1.3.2 x_цм = Σmᵢxᵢ/Σmᵢ (в равновесии x_цм = x_O). Груз правее опоры — момент по часовой.

**Контрольные наборы.**
| набор | M_по | M_против | итог | x_цм |
|---|---|---|---|---|
| x_O = 1; m₁ = 2, x₁ = 0,6; m₂ = 1, x₂ = 1,8 (по умолч.) | 8 Н·м | 8 Н·м | равновесие, N = 30 Н | 1 м |
| x_O = 1; m₁ = 2, x₁ = 0,6; m₂ = 2, x₂ = 1,8 | 16 Н·м | 8 Н·м | по часовой | 1,2 м |
| x_O = 0,5; m₁ = 3, x₁ = 0; m₂ = 0,5, x₂ = 1,5; балка M = 2 | 15 Н·м (балка 10 + груз 5) | 15 Н·м | равновесие, N = 55 Н | 0,5 м |
| x_O = 1; m₁ = 2, x₁ = 0,6; m₂ = 1, x₂ = 1,8; m₃ = 1, x₃ = 0 | 8 Н·м | 18 Н·м | против часовой | 0,75 м |
