## pendulums — Математический и пружинный маятники
Коды: 1.5.1, 1.5.2.

**Что показывает.** Анимация маятника (векторы v и a), синхронные графики x(t), v_x(t), a_x(t) на интервале 2T с бегущей отметкой, столбики E_к и E_п. x(t) = A·sin(ωt + φ₀), φ₀ = π/2 (старт из крайнего положения). Для математического маятника при α₀ > 15° — предупреждение: T = 2π√(l/g) верна только для малых колебаний.

**Параметры.** Тип; l 0,1–2,5 м; α₀ 2–40°; m 0,1–2 кг; k 10–200 Н/м; A 0,02–0,2 м (пружинный); флажок «замедлить в 5 раз».

**Формулы (1.5.1, 1.5.2).** ω = √(g/l) или √(k/m); T = 2π/ω; ν = 1/T; v_max = ωA; a_max = ω²A; E = mv_max²/2 = kA²/2 (для математического k = mω² = mg/l); a_x = −ω²x; период изменения энергии T/2. Для математического A ≈ l·α₀ (α₀ в радианах, малые углы). У математического маятника стрелка a_τ — касательная составляющая ускорения (= a_x гармонической модели).
