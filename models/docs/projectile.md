## projectile — Бросок под углом к горизонту (1.1.7)

**Что показывает.** Траекторию (вся — штрихом, пройденная — сплошной), тело в момент t с векторами →v, vₓ, v_y; отметки H (вертикальный штрих от вершины) и L (размерная линия); угол α; обрыв высотой h₀. Одинаковый масштаб по осям, подстраивается, чтобы траектория помещалась. При α = 45° и h₀ = 0 — подпись «L максимальна». Анимация с автозапуском (кроме prefers-reduced-motion), ползунок t (0…T).

**Параметры.** v₀ 0…30 м/с; α 0…90°; h₀ 0…50 м; t 0…T.

**Формулы (B1, 1.1.7).** x = v₀cosα·t; y = h₀ + v₀sinα·t − gt²/2; vₓ = v₀cosα; v_y = v₀sinα − gt; |v| = √(vₓ² + v_y²); t_п = v₀sinα/g. При h₀ = 0: T = 2v₀sinα/g, H = (v₀sinα)²/(2g), L = v₀²sin2α/g. При h₀ > 0 (формулы шпаргалки неприменимы): T — корень y(T) = 0, T = (v₀sinα + √((v₀sinα)² + 2gh₀))/g; H = h₀ + (v₀sinα)²/(2g) (над землёй); L = v₀cosα·T. g = 10 м/с².

**Контрольные наборы.**

|---|---|---|---|---|
| 20; 45°; 0 | 1,41 с | 2,83 с | 10 м | 40 м |
| 20; 30°; 0 | 1 с | 2 с | 5 м | 34,64 м |
| 20; 90°; 0 | 2 с | 4 с | 20 м | 0 |
| 10; 0°; 20 | 0 | 2 с | 20 м | 20 м |
| 10; 30°; 15 | 0,5 с | 2,3 с | 16,25 м | 19,94 м |

Текущие: v₀ = 20, α = 45°, t = 1 с → x = 14,14 м, y = 9,14 м, vₓ = 14,14, v_y = 4,14, |v| = 14,74 м/с. Для (10; 0°; 20) при t = 2 с: v_y = −20, |v| = 22,36 м/с.
