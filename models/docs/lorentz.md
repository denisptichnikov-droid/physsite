# lorentz — Заряженная частица в однородном магнитном поле

**Коды:** 3.3.4. **Файл:** `models/lorentz.js`.

## Что показывает
Частица (электрон / протон / α-частица) влетает в однородное поле B (⊙ к нам / ⊗ от нас), v ⟂ B, и движется по окружности. Анимация со следом траектории; в текущей точке — →v (по касательной) и →F_Л (к центру). Масштабная линейка (1–2–5·10ⁿ: мкм/мм/см/м) — окружность автоматически занимает 40–100 % рисунка, реальный R — на линейке и в таблице. Анимация условная: один оборот за 4 с.

## Параметры
- Частица: электрон (q = −1,6·10⁻¹⁹ Кл, m = 9,1·10⁻³¹ кг), протон (+1,6·10⁻¹⁹, 1,673·10⁻²⁷), α-частица (+3,2·10⁻¹⁹, 6,64·10⁻²⁷ ≈ 4 а.е.м.). <!-- CHECK: масса α-частицы в B0 не указана, взято 4·1,66·10⁻²⁷ -->
- Направление B: ⊙ / ⊗ (по умолчанию ⊗).
- v: 0,1…10 ·10⁶ м/с (шаг 0,1), по умолчанию 1·10⁶. v ≪ c (≤ 3,3 % c), нерелятивистски.
- B: 1…500 мТл (шаг 1), по умолчанию 100 мТл. B > 0 и v > 0 — деления на ноль нет.

## Формулы (B3.3.4)
- $F_Л = |q|vB$ (α = 90°)
- $R = \dfrac{mv}{|q|B}$, $T = \dfrac{2\pi m}{|q|B}$
- Направление: $\vec\omega = -q\vec B/m$ → q > 0 и B ⊙: по часовой; знак q или B меняет направление. Правило левой руки (для отрицательной — пальцы против скорости).
