# grating — Дифракционная решётка

Коды: 3.6.11, 3.6.12.

**Что показывает.** Нормальное падение на решётку, лучи к максимумам под истинными углами, экран на расстоянии L (в масштабе, ширина рисунка ≈ 2,4 м), метки максимумов с номерами m, дуга φ₁. Режим «белый свет»: m = 0 — белая полоса, остальные порядки — спектры (фиолетовый ближе к центру), видно перекрытие 2-го и 3-го порядков.

**Параметры.** N = 100…1000 штрихов/мм (шаг 50), d = 1/N; λ = 380…760 нм (шаг 10); L = 0,2…2 м; флажок «белый свет».

**Формулы (B4, 3.6.11).** d sin φ_m = mλ; d = l/N; k_max = ⌊d/λ⌋; всего 2k_max + 1; x_m = L·tg φ_m; при малых углах x ≈ mλL/d (выводится рядом для сравнения).

Белый свет: «полных спектров» — k_max для 760 нм; спектры m и m+1 перекрываются, если (m+1)·380 < m·760 (впервые при m = 2).
