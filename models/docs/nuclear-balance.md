# Баланс A и Z в ядерных реакциях (`nuclear-balance`)
Коды: 4.3.1, 4.3.2, 4.3.4. Модель на DOM (без canvas), запись ядер — A сверху слева, Z снизу слева.

## Что показывает
Процессы: α-, β⁻-, β⁺-распад, γ-излучение для ядер ²³⁸U, ²²⁶Ra, ²¹⁰Po, ¹⁴C, ¹³¹I, ⁶⁰Co, ⁴⁰K, ²²Na — продукт по правилам смещения (таблица символов Z = 1…96). Если выбранный тип распада не характерен для ядра — пометка. Режим «реши сам»: пользователь вводит A и Z неизвестного (или число частиц x), проверка сумм с ✓/✗, кнопка «Показать ответ». Режим «ядерная реакция» — 8 типовых реакций.

## Формулы (часть B)
- N = A − Z (4.3.1)
- α: A − 4, Z − 2; β⁻: Z + 1 (+ ⁰₋₁e + ν̃); β⁺: Z − 1 (+ ⁰₊₁e + ν); γ: A, Z не меняются (4.3.2)
- Σ A и Σ Z сохраняются (4.3.4)

## Контрольные наборы
1. α, ²³⁸₉₂U → ²³⁴₉₀Th + ⁴₂He; ΣA 238 = 238, ΣZ 92 = 92; N продукта 144.
2. β⁻, ¹⁴₆C → ¹⁴₇N + ⁰₋₁e + ν̃; ΣZ 6 = 7 − 1.
3. β⁺, ²²₁₁Na → ²²₁₀Ne + ⁰₊₁e + ν.
4. α, ²²⁶₈₈Ra → ²²²₈₆Rn; ²¹⁰₈₄Po → ²⁰⁶₈₂Pb. β⁻: ¹³¹₅₃I → ¹³¹₅₄Xe; ⁶⁰₂₇Co → ⁶⁰₂₈Ni; ⁴⁰₁₉K → ⁴⁰₂₀Ca.
5. Реакции (ответ «?»): ¹⁴N + ⁴He → ¹⁷O + ¹₁p; ⁹Be + ⁴He → ¹²C + ¹₀n; ²⁷Al + ⁴He → ³⁰₁₅P + n; ²H + ³H → ⁴He + ¹₀n; ⁶Li + n → ³₁H + ⁴He; ⁷Li + p → 2·⁴₂He; ¹⁴C → ¹⁴N + ⁰₋₁e + ν̃; ²³⁵U + n → ¹⁴¹Ba + ⁹²Kr + x·n, x = 3 (ΣA 236 = 141 + 92 + 3).
