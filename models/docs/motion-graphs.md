## motion-graphs — Графики равноускоренного движения (1.1.3, 1.1.5, 1.1.6)

**Что показывает.** Тело на оси x (векторы →v, →a) и три синхронных графика x(t), vₓ(t), aₓ(t) на 0…10 с. На vₓ(t) закрашена площадь от 0 до t (зелёная выше оси, красная ниже) = перемещение sₓ; на x(t) — касательная в текущей точке (наклон = vₓ). Ползунок t и анимация «Пуск» (без автозапуска).

**Параметры.** x₀ −10…10 м (шаг 1); v₀ₓ −10…10 м/с (шаг 1); aₓ −4…4 м/с² (шаг 0,5); t 0…10 с.

**Формулы (B1).** 1.1.6: x = x₀ + v₀ₓt + aₓt²/2, vₓ = v₀ₓ + aₓt; 1.1.2: sₓ = x − x₀; путь: если разворот t* = −v₀ₓ/aₓ ∈ (0; t), то l = |x(t*) − x₀| + |x(t) − x(t*)|, иначе l = |sₓ|. Лайфхак 1.1.6: наклон x(t) = v, площадь под v(t) = перемещение.
