# phase-graph — График t(Q): нагрев, плавление, кипение

**Что показывает.** График t(Q) для вещества массой m (вода/лёд/пар, нормальное давление), которое нагревают от t₀ до 150 °C. Участки:
- ① нагрев льда;
- ② плавление — горизонтальный участок, Q = λm;
- ③ нагрев воды;
- ④ кипение — горизонтальный участок, Q = Lm;
- ⑤ нагрев пара.

По графику бежит точка (слайдер Q или кнопка «Пуск»). В readout: текущая t, агрегатное состояние, масса расплавившегося или испарившегося вещества, Q каждого участка.

**Параметры.**
- m = 0,1…2 кг.
- t₀ = −50…140 °C, шаг 5. При t₀ = 0 °C в начале лёд, при t₀ = 100 °C — вода.
- Слайдер Q — доля полной теплоты, 0…100 %; рядом показано значение в кДж.

**Табличные данные:** c_льда = 2100 Дж/(кг·К), λ = 3,3·10⁵ Дж/кг, c_воды = 4200 Дж/(кг·К), L = 2,3·10⁶ Дж/кг, c_пара = 2000 Дж/(кг·К).

**Формулы (часть B).** 2.2.4: Q = cmΔt. 2.2.5: Q = λm, Q = Lm. 2.1.15–2.1.17: при фазовом переходе температура постоянна.

**Контрольные наборы.**
1. m = 1 кг, t₀ = −20 °C.
   - Q₁ = 4,2·10⁴ Дж, Q₂ = 3,3·10⁵ Дж, Q₃ = 4,2·10⁵ Дж, Q₄ = 2,3·10⁶ Дж, Q₅ = 1·10⁵ Дж.
   - Q полное = 3,19·10⁶ Дж.
   - При Q = 50 % (1,596·10⁶ Дж): t = 100 °C, вода + пар, испарилось 0,35 кг.
2. m = 0,5 кг, t₀ = −40 °C.
   - Q₁ = 4,2·10⁴ Дж, Q₂ = 1,65·10⁵ Дж, Q₃ = 2,1·10⁵ Дж, Q₄ = 1,15·10⁶ Дж, Q₅ = 5·10⁴ Дж.
   - Q полное = 1,62·10⁶ Дж (1,617·10⁶).
3. m = 2 кг, t₀ = 20 °C (вода).
   - Q₃ = 6,72·10⁵ Дж, Q₄ = 4,6·10⁶ Дж, Q₅ = 2·10⁵ Дж.
   - Q полное = 5,47·10⁶ Дж.
   - При Q = 10 % (5,472·10⁵ Дж): t = 20 + 547200/8400 ≈ 85,1 °C, вода.
