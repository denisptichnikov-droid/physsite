# Физическая проверка моделей (physics-expert)

Объём: 35 моделей `models/*.js` и их описания `models/docs/<id>.md`. Node и Playwright недоступны, поэтому проверка шла так:
- читал код вычислений и строки readout;
- независимо пересчитывал все контрольные наборы из docs в python (`python -I`) по формулам части B;
- предельные случаи A9.1 и направления проверял по коду;
- контракт A6 проверял grep-ом по всем файлам и выборочным чтением.

Итог: **blocker 0, major 0, minor 5**. Все числа в docs (больше 130 значений) совпали с независимым расчётом. Код выводит в readout те же величины с теми же единицами. Направления верны: сила Лоренца и Ампера по правилу левой руки (с учётом знака заряда), правило Ленца, буравчик, знаки Q на участках цикла, ход лучей в линзах, ПВО.

Проверено, ошибок нет:
- **Контракт A6.** У всех 35 моделей есть кнопка «Сброс» (`{ reset: true }`). destroy всегда передаётся как `d.run`. Освобождение ресурсов:
  - во всех моделях на canvas: `cv.destroy` (ResizeObserver);
  - у анимаций: `anim.destroy` (rAF и visibilitychange);
  - pointer-слушатели снимаются в lens-builder, refraction, plane-mirror, double-slit, field-lines, magnetic-lines;
  - собственный rAF отменяется в field-lines и magnetic-lines;
  - `<style>` удаляется в nuclear-balance;
  - есть подписка `onThemeChange`.
- **Предельные случаи** (проверены по коду, NaN/∞ в readout нет):

  | Случай | Модели и результат |
  |---|---|
  | α = 0° | projectile (T = √(2h₀/g), L = 0 при h₀ = 0), incline (покой), refraction (β = 0), prism (ПВО — ✓ по расчёту) |
  | α = 90° | projectile (L = 0), incline: «tgα не определён», N = 0, a = g |
  | d = F | lens-builder: «изображения нет», f = ∞, Γ — «—» |
  | T_х → 0 | carnot: η = 100 % с пояснением, V₃ и V₄ = ∞ корректно обрезаны |
  | v = 0 | circular-motion: T — «—», ν = 0; rails-induction: ток «нет»; projectile при v₀ = 0 |
  | μ = 0 | incline, pulleys (стол), energy-bars (строка s = h/μ не выводится) |
  | q = 0 | field-lines: заряд исключён из поля, E_i = 0 |
  | Деление на ноль | Защищено: circuit (R + r = 0), lorentz (B ≥ 1 мТл), circular-motion (R ≥ 0,5), wave и resonance (T, k > 0), motion-graphs (yRange вырожденный → [−1; 1]), collisions (удара нет при v₁ ≤ v₂) |

- **Направления:**
  - lorentz: s = sign(q)·(⊙ ? 1 : −1). Протон ⊗ движется против часовой, электрон ⊗ — по часовой. →F_Л направлена к центру. Касательная к траектории = производной положения.
  - rails-induction: ⊗, v > 0 → ток против часовой; ⊙, v > 0 → по часовой; ⊗, v < 0 → по часовой. F_A всегда против v (проверено как Il×B).
  - magnetic-lines: ⊙ → линии против часовой; B в центре витка и внутри катушки вправо при «вверху ⊙»; у магнита снаружи N→S.
  - lens-builder: три луча построены верно для обоих типов линз; мнимые изображения показаны пунктиром.
  - cycle-work: знаки Q верны и при обходе против часовой (порядок kinds после разворота сверен).
  - photoeffect: при U > 0 электроны ускоряются к аноду, при U < 0 тормозятся, условие остановки E₀ < −eU.
  - pendulums, wave: волна бежит в +x.
