# REPORT — справочный сайт «ЕГЭ по физике»

Дата: 2026-10-27. Руководитель: основная сессия Claude Code.

## Как запустить

```bash
python -m http.server 8000
```
Открыть http://localhost:8000. Нужен статический сервер (страницы грузятся через fetch, как файл не откроется).
Внешние зависимости — только CDN: KaTeX 0.16.11, marked 12.0.2.

## Итоги проверки

**Автоматический прогон (встроенный браузер)**, все 61 маршрут, светлая и тёмная тема:
- ошибок и предупреждений в консоли нет, все 35 моделей монтируются и корректно уничтожаются;
- нераспознанных формул KaTeX нет (4 ошибки синтаксиса `\,'` найдены и исправлены);
- на ширине 320px горизонтального скролла нет ни на одной странице.

**Эксперт по физике** (`qa/physics-report-content-1.md`, `-content-2.md`, `-models.md`):
- покрытие кодификатора: каждый код 1.1.1–4.3.4 — ровно на одной странице, бейджи БУ/УУ совпадают;
- формулы совпадают с частью B; углы в $F_A$, $F_Л$, $\Phi$, $\mathcal E_i$ — по кодификатору;
- модели: ~130 контрольных значений пересчитаны независимо — все ✓; направления (Лоренц, Ленц, буравчик, ход лучей) верны.
- Найдено и исправлено: 2 major (ошибочная логика в обосновании №26 изобары; неверный ответ T в LC-контуре), 25 minor.

**Тестировщик дизайна** (`qa/design-report.md`): текст проходит AA в обеих темах, фокус видимый, у всех контролов есть подписи.
Исправлено: 3 major (контраст рамок контролов, управление перетаскиванием с клавиатуры, контраст спектральных цветов), часть minor.

## Что осталось / ограничения

1. **Node.js в окружении нет**, поэтому Playwright-тестов (`tests/*.spec.ts`) нет; проверка — прогоном во встроенном браузере и статическим аудитом. Скриншотов в `qa/screenshots/` нет.
2. **Печать «Все формулы»** не проверялась на реальном принтере/PDF.
3. **Кодификатор 2027 — ПРОЕКТ** (B8): перед публикацией сверить коды с финальной версией на fipi.ru; константы B0 — с актуальной демоверсией.
4. **Метки `<!-- CHECK -->`** (~60 мест: следствия и справочные значения вне части B) эксперт счёл физически верными, но они не из кодификатора — решение «оставить» за владельцем проекта.
5. Мелочи, оставленные сознательно:
   - в field-lines объект, выбранный с клавиатуры, не подсвечивается на рисунке (сообщается через aria-label);
   - «Сброс» в plane-mirror не возвращает переключатель клавиатуры;
   - цвета векторов местами используются для не-векторных элементов (подписи, Q) — без путаницы ролей F/v/a/E/B;
   - в моделях часть масштабов условная (подписано в самих моделях).
6. Нарушение владения файлами: руководитель сам исправил 4 формулы `\,'` → `\,{}'` в content (механическая правка KaTeX) и собрал `models/README.md` из `models/docs/*.md` (вместо прямой записи моделистами — чтобы 7 параллельных агентов не писали в один файл).

## Изменение после приёмки (по решению заказчика)

Коды кодификатора и уровни БУ/УУ убраны из всего, что видит ученик: шапки страниц, меню, главная, обзоры разделов, поиск, «Все формулы», заголовки и текст теории. Служебные метаданные остались только в скрытых комментариях `<!-- codes … -->` и в `data/structure.json` (для сверки с кодификатором). Добавлены версии `?v=2` к скриптам и стилям, чтобы браузеры не держали старые файлы; при следующих правках JS/CSS версию нужно увеличивать.
