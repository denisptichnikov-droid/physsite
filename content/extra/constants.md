# Константы и справочные данные

Значения физических постоянных и единиц, которые используются во всех формулах и моделях сайта. Если в условии задачи дано другое значение — берите значение из условия.

> [!theory] Важно
> Значения приведены по стандартным справочным материалам КИМ ЕГЭ и **сверяются с актуальной демоверсией ФИПИ**. Ускорение свободного падения на сайте везде принято $g = 10$ м/с².

## Физические постоянные

| Величина | Значение |
|---|---|
| Ускорение свободного падения | $g = 10$ м/с² |
| Гравитационная постоянная | $G = 6{,}7\cdot10^{-11}$ Н·м²/кг² |
| Универсальная газовая постоянная | $R = 8{,}31$ Дж/(моль·К) |
| Постоянная Больцмана | $k = 1{,}38\cdot10^{-23}$ Дж/К |
| Постоянная Авогадро | $N_A = 6\cdot10^{23}$ моль⁻¹ |
| Скорость света в вакууме | $c = 3\cdot10^8$ м/с |
| Коэффициент в законе Кулона | $k = \frac{1}{4\pi\varepsilon_0} = 9\cdot10^9$ Н·м²/Кл² |
| Электрическая постоянная | $\varepsilon_0 = 8{,}85\cdot10^{-12}$ Ф/м |
| Модуль заряда электрона (элементарный заряд) | $e = 1{,}6\cdot10^{-19}$ Кл |
| Постоянная Планка | $h = 6{,}6\cdot10^{-34}$ Дж·с |
| Масса электрона | $m_e = 9{,}1\cdot10^{-31}$ кг |
| Масса протона / нейтрона | $1{,}673\cdot10^{-27}$ / $1{,}675\cdot10^{-27}$ кг |
| 1 электронвольт | $1$ эВ $= 1{,}6\cdot10^{-19}$ Дж |
| 1 атомная единица массы | $1$ а.е.м. $= 1{,}66\cdot10^{-27}$ кг |
| Энергетический эквивалент 1 а.е.м. (энергия покоя массы 1 а.е.м.) | ≈ 931,5 МэВ |
| Нормальное атмосферное давление | $10^5$ Па |
| Абсолютный ноль температуры | 0 К = −273 °C |

Обратите внимание: буквой $k$ обозначают две разные величины — постоянную Больцмана (молекулярная физика) и коэффициент в законе Кулона (электростатика). Какая из них нужна, понятно из раздела.

## Десятичные приставки

| Приставка | Обозначение | Множитель |
|---|---|---|
| пико | п | $10^{-12}$ |
| нано | н | $10^{-9}$ |
| микро | мк | $10^{-6}$ |
| милли | м | $10^{-3}$ |
| санти | с | $10^{-2}$ |
| кило | к | $10^{3}$ |
| мега | М | $10^{6}$ |
| гига | Г | $10^{9}$ |

Примеры: $1$ нм $= 10^{-9}$ м, $5$ мкФ $= 5\cdot10^{-6}$ Ф, $2$ МэВ $= 2\cdot10^{6}$ эВ, $1$ см² $= 10^{-4}$ м².

## Перевод единиц

| Из чего | Во что | Как перевести |
|---|---|---|
| электронвольты | джоули | $1$ эВ $= 1{,}6\cdot10^{-19}$ Дж (умножить) |
| джоули | электронвольты | разделить на $1{,}6\cdot10^{-19}$ |
| градусы Цельсия | кельвины | $T = t + 273$ |
| кельвины | градусы Цельсия | $t = T - 273$ |
| литры | кубические метры | $1$ л $= 10^{-3}$ м³ $= 1$ дм³ |
| атмосферы | паскали | $1$ атм $\approx 1{,}01\cdot10^{5}$ Па (в задачах обычно $10^5$ Па) |
| километры в час | метры в секунду | разделить на 3,6: $36$ км/ч $= 10$ м/с |
| метры в секунду | километры в час | умножить на 3,6 |

> [!tip] Лайфхак
> Перевод площади и объёма — это перевод длины в квадрате и в кубе: $1$ см $= 10^{-2}$ м, значит $1$ см² $= 10^{-4}$ м², $1$ см³ $= 10^{-6}$ м³; $1$ мм² $= 10^{-6}$ м².
